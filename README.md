# sim-evo
Эксперементальный пет-проект песочницы симуляций естесвенного отбора и эволюции генома.

Управление:

ПКМ - перемещение камеры

СКМ - маштабирование


Синие точки - травоядные существа

красные точки - хищники

Оранжевые точки - всеядные существа

Серые точки - мертвые тела

Точки внутри существ - индикатор голода от зеленого к желтому до красного.

Зеленые и розово-фиолетовые точки - растительная пища. Цвет зависит от гена ядовитости.
